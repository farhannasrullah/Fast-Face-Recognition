2.7_80x80_MiniFASNetV2.onnx dan 4_0_0_80x80_MiniFASNetV1SE.onnx

Sumber   : Silent-Face-Anti-Spoofing, Minivision AI
           https://github.com/minivision-ai/Silent-Face-Anti-Spoofing
Lisensi  : Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0)
Konversi : bobot TensorFlow.js dari paket npm "open-face-liveness" (MIT) dikonversi ke ONNX NCHW
           dengan tools/convert_minifasnet_tfjs.py. Keluaran ONNX diverifikasi sama dengan model
           tfjs asli (selisih maksimum logit < 2e-6 pada input acak dan wajah nyata).
Input    : 1x3x80x80, BGR, nilai piksel 0-255 tanpa normalisasi; crop wajah diperbesar 2,7x / 4,0x.
Output   : logit 3 kelas [kertas/print, asli, layar/replay] -> softmax.

face_detection_yunet_2023mar.onnx dan face_recognition_sface_2021dec.onnx (diunduh otomatis):
           OpenCV Zoo, https://github.com/opencv/opencv_zoo (YuNet: MIT, SFace: Apache-2.0).
